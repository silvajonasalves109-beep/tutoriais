# Tutoriais @mindloop_u

Site estático: cada tutorial é uma pasta com um `index.html`.

- `/` → lista de tutoriais (index.html da raiz)
- `/codigo` → "Como fazer um vídeo feito de código"

## Novo tutorial
1. Crie a pasta com o nome curto do link (ex.: `carrossel/index.html`).
2. Adicione um cartão na lista do `index.html` da raiz.
3. Envie para o GitHub: a Vercel publica sozinha em ~30 s.

Link de cada tutorial: `https://<seu-projeto>.vercel.app/<pasta>` (ex.: `/codigo`).
